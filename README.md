# 异星之躯 · ALIEN BODY

一个机器人，在陌生文明之间寻找自己的来历。第三人称 3D 单机动作冒险，包含四个可完成的章节、机器人伙伴、身体改造、本地存档、两个结局及通关后重访。

## 开源与发行 · 1.6.0-rc.1

### 这一版的游戏体验提升

- 开场缩短为三条提示；进入游戏后，根据实际操作逐步学习移动、跳跃、冲刺、射击和扫描。
- 每章三份可选旅途补给，包含十二段原创记录、零件奖励和集齐奖励；收集进度保存，日志可回看。
- 四章加入各自的环境装置、浮游粒子和合成音乐；低画质与减少动态效果设置继续生效。
- 巡逻清场、守卫解除与补给回收有明确反馈；音乐、动作音效分别控制音量。

### 源码快速开始

需要 Node 22.13+（22 或 24+）和 Python 3.10+：

```sh
git clone https://github.com/zbyisredeemer/machine-explo-universe-web-game.git
cd machine-explo-universe-web-game
npm ci
npm run dev
```

浏览器打开终端显示的地址。源码仓库不携带 dist；要使用离线启动器，先运行 `npm run build`。

### 验证与生成发行包

```sh
npx playwright install chromium
npm run release
```

这条命令自动启动独立服务，依次完成静态检查、单测、安全审计、构建及完整浏览器回归，生成 `artifacts/` 下的离线 ZIP、源码 ZIP 和 SHA-256 校验清单。打包拒绝未验证或已变更的源码、构建和报告。单独验证用 `npm run verify`，复用当前有效证据打包用 `npm run package`。

离线 ZIP 解压后：macOS 双击 `启动游戏.command`，Windows 双击 `start-game.cmd`，Linux 执行 `sh start-game.sh`。只需要 Python 3.10+。完整部署与升级步骤见发行指南。

### 数据可靠性与支持

存档失败会持续提示并保留导出入口，恢复自动备份会通知玩家。设置 → 版本、隐私与支持，可查看当前版本、存储政策和导出不含存档正文的诊断信息。诊断不会自动发送。

## 开始游戏

macOS 双击项目根目录的 **启动游戏.command**。启动器使用 Python 3 在本机打开游戏，不需要在线账户。请保留启动窗口，关闭时按 Control+C。

或者执行：

```sh
python3 scripts/serve.py
```

默认地址为 `http://127.0.0.1:4174`。若该端口已被其他应用使用，启动器会选择下一个空闲端口。存档按浏览器和地址分别保存；继续原有进度时请使用相同浏览器和地址。

已构建的 `dist/` 包含全部程序和程序化美术。首次安装依赖需要联网；之后从本地启动构建可断网游玩。桌面键盘和鼠标为主要输入方式，需要支持 WebGL 2 的浏览器。

## 旅程

1. **巨舰墓场**：结识维修机器人铆钉，恢复巨舰中继，获得重力锚，揭开维生系统的秘密。
2. **漂流花园**：认识以生命储存记忆的文明，取得共生核心，把一株幼苗带回飞船。
3. **慢速之海**：帮助不同时间尺度的居民恢复同步，获得时差引擎。
4. **群星之间**：取得折跃感知，解除最后的指令，为自己的旅程选择方向。

每章包含中继、维护舱、能力通路、守卫、文明发现、记忆碎片和一条可选支线。取得相应模块后，可以回到私人信号处帮助对方；日志会记录带来的变化。通关后可以从飞船重访旧章节；折跃感知让之前不可读的隐藏记录变得可见。

飞船中有导航台、改造工作台、观测窗和种植箱。邀请铆钉后，它会留在船上，记得你是否找回旧工具，并对新部件与旅程变化作出反应。

## 存档与设置

完成任务节点、取得物品、击败敌人和改造后自动保存。刷新或重启从最近任务节点继续；生命和修复包在节点恢复。失败后保留已取得的部件、记录和重要世界变化。

存档保存在浏览器的 `localStorage`，没有上传服务。清除站点数据或选择“新的旅程”会移除当前进度。设置提供故事/标准难度、音量、画面质量、镜头震动、灵敏度和辅助瞄准范围。

每次更新存档时保留上一次有效检查点，主存档损坏时尝试恢复备用档。重要旅程建议使用设置中的“导出存档”保留文件；导入前会显示该档案的文明数与游玩时间，并让你选择是否替换当前进度。浏览器拒绝持久存储时仍可游玩，但请在离开前导出备份。

## 开发与验证

下列命令用于完整源代码工程。离线 ZIP 只包含运行所需文件，无需安装开发依赖。

```sh
npm ci
npm run dev -- --port 4173
npm test
npm run build
```

开发服务器运行时，可以在另一个终端执行：

```sh
npm run test:e2e
npm run test:branches
npm run test:polish
npm run test:directed
npm run test:robot
npm run test:inspection
npm run test:motion
npm run test:combat
npm run test:guidance
npm run test:enemies
```

端到端测试使用 Playwright Chromium。未安装时运行 `npx playwright install chromium`，或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定现有 Chromium 可执行文件。测试用真实键盘操作推进四章，验证战斗、装备、伙伴、刷新读档、结局、重访和暂停。死亡分支单独注入伤害验证。截图和测试报告保存在 `test-results/`。

测试访问 `?qa` 时，开发构建暴露 `__GAME__` 和 `__UI__` 供断言读取。生产构建不包含该入口。

运行本地构建启动器后，`npm run test:production` 验证生产入口、操作、设置、存档与无外部资源依赖。

## 技术与素材

- Three.js 渲染，Vite 构建；DOM 中文界面。
- 场景、机器人、敌人和特效均由代码生成；声音使用 Web Audio 合成。
- 不依赖在线图片、字体、实时 AI 服务或第三方账户。
- 原始设计与实现计划位于 `docs/plans/`；实际制作采用风格化程序美术与紧凑的四章关卡。

这是完整可玩的独立短篇实现，内容规模与商业大型单机不同。剧情、伙伴对话与世界反馈为预先编写的事件系统。
