# Changelog

## 1.6.0-rc.1 — 2026-10-08

- Replace the dense first-start instructions with three essentials and contextual training recognised from actual player actions.
- Add three optional supply discoveries per chapter, twelve original story records, persistent journal entries and once-only completion rewards.
- Add chapter-specific animated environmental accents and particles with low-quality and reduced-motion support.
- Add four synthesized musical palettes, independent music/effects volume and layered action sounds.
- Surface patrol clears, guardian defeats and collection rewards; include journal disclosures in modal keyboard navigation.
- Preserve v1 saves and extend release verification with exploration, input, audio-state and resource-boundary coverage.

## 1.5.0-rc.1 — 2026-10-06

- Establish MIT licensing, bilingual entry documentation, contribution/security/privacy guidance and release acceptance criteria.
- Add consistent dependency installation, lint/format checks, CI and isolated full-suite verification.
- Bind release packaging to source, build and report hashes; produce separate source/offline archives with SHA-256 checksums.
- Support static subdirectory deployment and Windows/macOS/Linux Python launchers; harden local file serving.
- Fix failed save retries and backup rotation failures; expose persistent storage warnings and backup recovery notifications.
- Add version/support information and local diagnostics export. Preserve backup export during runtime/graphics failure.
- Preserve four chapters, endings, procedural art, mechanics and existing v1 saves.

This is a release candidate. Cross-platform hardware and storefront acceptance remain separate from local automation results.
