# Architecture

游戏为 Vite 构建的静态站点。运行时唯一第三方依赖是 Three.js；游戏逻辑、剧情、场景与音效全部本地执行。

| 模块 | 职责 |
| --- | --- |
| `main.js` | 启动、设置加载、帧循环、图形设备/运行故障恢复 |
| `game.js` | 输入、战斗、状态转换、检查点与事件 |
| `state.js` / `storage.js` | v1 存档校验/修复、自动备份、持久化失败回退 |
| `data.js` | 四章剧情、模块和装备数据 |
| `world.js` / `environments.js` | 场景建立、材质/几何体资源与渲染 |
| `robot-*` / `enemy-*` | 机体造型、运动学、敌方外观与动画 |
| `ui.js` / `experience.js` | DOM 界面、焦点、导入导出、战斗反馈 |
| `guidance*` / `ability-effects.js` | 操作引导与主动技能反馈 |
| `tests/*.test.js` | 无浏览器的核心规则测试 |
| `tests/*.mjs` | Chromium 实际交互、完整旅程与专项回归 |
| `scripts/verify.mjs` | 统一验证、服务生命周期、当前文件 SHA-256 证据 |
| `scripts/package_release.py` | 证据复核、源码/离线 ZIP 与校验清单 |

输入 → Game 更新规则 → World 渲染；Game 事件驱动 UI。生产版本不暴露游戏对象，开发环境只有 `?qa` 打开读取/控制入口。

存储适配器保存本次会话的失败写入，但不会将其视为已持久化。写主存档前先保留有效旧存档；备份写入失败时保留旧主存档并通知玩家。加载顺序为主存档、备份、新状态，恢复来源向玩家明确展示。

游戏按节点续玩，不逐帧保存生命、坐标和敌人瞬时状态。维护时应保证 `validateSave` 对旧字段兼容，避免只改保存格式却遗漏导入、重试和通关重访。

未来适合拆分 `game.js` 中的输入与战斗职责；本版本先保留已回归的行为，避免为形式上的模块化扩大玩法风险。
