# 机体配色与敌人外观验证 · 2026-10-06

## 实现

- `data.js` 提供六种免费双色涂装，以及三种原有制作涂装；旧存档使用同一个 `equipment.skin` 字段继续兼容。
- 身体检视新增色卡、选中标志、锁定状态与实时预览，菜单和游戏中均可使用；工作台仍负责奖励涂装制作。
- 换肤替换当前机体及检视模型的装甲、点缀、灯光材质引用，不修改共享材质，不重新加载关卡。新旅程保留当前所选免费涂装。
- `enemy-styles.js` 统一四章敌方主题及三类小怪的配色，装甲附加到现有骨架；敌人行为、伤害与攻击判定未调整。

## 验证结果

- `npm test`：23 项通过，新增免费配色存档往返和旧值回退验证。
- `npm run test:appearance`：六种配色实际点击、预览/主角同步、NPC 材质隔离、菜单到新旅程保留配色、960×640 布局、换肤不重置血量/能源/冷却/位置/敌人、奖励锁定、存档重载、四章敌方色系通过。浏览器错误为空。
- 连续三轮配色切换，预热后的 GPU 资源保持 336 个几何体、14 个纹理，没有随切换轮次增长。
- `npm run test:enemies`：四章 Boss 的固定步长转向/步态、护板开合和炮管后坐通过，支撑脚误差小于 0.035。
- `npm run test:inspection`：8 次开关资源边界、小窗口、键盘焦点循环、图形设备丢失与恢复通过。
- `npm run test:combat`：12 组移动、冲刺、空中转向、枪口对准、近距离射击、锁定、暂停与失焦清理检查通过。
- `npm run build`：成功。主 JS 947.38 kB（gzip 263.70 kB），保留原有大于 500 kB 的构建体积提示。
- `npm run test:production`：正式构建的配色点击与保存续玩、移动、设置、小窗口、无外部请求及无 QA 全局变量通过。
