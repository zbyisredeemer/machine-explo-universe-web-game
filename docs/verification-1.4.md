# 1.4 机体与场景验证

日期：2026-10-03

## 本轮改动

- 守卫与巡逻机使用机械零件构造器，按骨骼和材质合并刚性零件并复用几何。四足包含髋、膝、踝、足底与活动连杆；切割工具旋转，炮组后坐，核心暴露时散热护板打开。四章采用反应炉、生物储罐、钟面和陀螺结构。
- 主角推进与步行状态分离，落地重新建立支撑点，急转触地限制在可达区域。避免冲刺尝试接地、旧落点拉伸腿部的问题。
- 建筑使用共享粗糙度和微表面贴图；巨舰揭示区域的活动门增加独立面板、加固条和中缝灯。
- 精细模式增加半分辨率 GTAO 接触暗部，透明玻璃、大气壳与攻击覆盖层不参与遮挡。太阳阴影范围跟随可玩前景，提高近处细节；低画质继续直接渲染。

## 实机审查

`enemy-1-detail.png` 至 `enemy-4-detail.png` 是关卡光照下的机体近景，可辨认关节、连杆、脚底、工具和不同核心；`v12-chapter-*-attack.png` 为本轮重新截取的实际战斗画面，保留地面预警。

主角检视和实机移动录制为 `robot-motion-preview.mp4`。本轮变化加强了机械结构和接地表现，但当前仍呈现风格化程序美术。大面积建筑、植被和岩石的细节密度没有达到写实资产的水平；四种守卫共用底盘轮廓，动作也未采用完整动力学或手工精修动画。

## 完成范围

本版完成敌方结构、复杂动作修正和场景光照这一阶段，并交付完整可玩的离线短篇。四章规模、编写式伙伴对话和事件系统不等于大型开放世界或实时 AI 生活模拟。不能把测试通过解释为已经达到用户提出的整体商业生产级观感目标。

## 运行与资源

本机 Chromium、1440×900、精细模式的 120 帧样本：中位数 16.7 ms，95 分位 17.7 ms。三轮五场景切换保持 388 几何、10 纹理。锁定、伤害反馈、完美闪避、存档导入导出、失焦清键、拒绝存储和图形设备恢复通过。此样本不能外推为所有硬件或最繁忙战斗的帧率保证。

生产构建验证通过：无 QA 全局、无外部资源请求，检视入口、实际键盘移动、画质设置、960×640 布局、3000×1700 像素预算与刷新读档正常。离线包逐文件校验 SHA-256，并验证启动器可执行位。构建仍提示单个 JS 包超过 500 kB；本版保留本地一次加载，未掩盖该提示。
