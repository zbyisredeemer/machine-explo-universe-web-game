# 1.2 场景与战斗更新验证记录

日期：2026-10-03

## 实际改动

- 四章分别构建服务舱与反应堆、异星温室、钟摆城市、破碎天文台。主线交互坐标保留以兼容存档；关卡仍采用紧凑的前进探索结构。
- 重新制作有肩、肘、膝关节的机器人，增加面罩、工具、近战刃和背包推进器；重做巡逻机与四位守卫的造型。
- 四种守卫招式具备独立地面预警、碰撞区域和核心暴露窗口。攻击区域采用直线、圆形或扩散环；锚定与共生模块可以打断尚未触发的攻击。
- V 扫描、四条私人信号支线、存档中的帮助结果与能力变化。第一章的小信使会出现在飞船上；日志记录四条支线的后果。
- 可跳过的入场与守卫镜头、扫描标注、攻击提示；减少动态效果设置保留。
- 环境反射、纹理甲板和静态实例化。每章 707—1,123 个环境构件合并为 26—35 批；这是静态建筑的批次数，不是整帧全部绘制调用数。

## 性能样本

本机 Chromium，1440×900，精细模式，120 帧样本：帧时间中位数 16.7 ms，95 分位 18.0 ms，渲染像素 1,296,000。

连续三轮、每轮切换五个场景后，测量点均为 230 个几何资源、7 个纹理资源，未呈现持续增长。资源计数是该测试场景与配置下的采样，不是所有场景的峰值。

## 交付范围

这是桌面键盘鼠标操作的四章独立短篇。角色、环境和声音为程序化素材，叙事为编写的事件系统；没有实时大模型 NPC、开放世界、大型商业作品级素材与内容量，也未做全平台设备认证。完整通关与性能样本是本地交付证据，不等同于所有设备的稳定性保证。

离线发行包由 `scripts/package_release.py` 生成：要求各浏览器测试报告新于本轮源文件，并校验 ZIP 内每个发行文件的 SHA-256 与启动脚本执行位。版本与摘要记录在 `release.json`。
