# 1.3 机械身体阶段验证与完成审查

日期：2026-10-03

## 已完成并有证据的改动

- 主角、铆钉与信使使用新的工业机器人骨架。护板、轴承、金属芯轴、线束、散热结构、三指夹爪与多目传感器在近景检视图中可辨认。
- 膝部伸缩连杆根据两端骨骼的实际世界位置更新；髋、膝、踝使用双段 IK，脚踝抵消上游旋转以保持脚底平整。
- 世界坐标的支撑脚落点、加速提前抬脚、落点预测、停止回收步、落地缓冲、受击姿态和瞄准俯仰已经接入实际游戏循环。
- 主角与附近交谈对象/锁定目标的头部注视、持械动作、后坐、脚步与落地声已接入。
- I 键和可点击身体按钮进入检视，支持旋转、缩放、局部聚焦与四种动作展示；退出恢复原模式，检视期间不会推进战斗。
- 检视画面的刚性零件按骨骼和材质合并，重复打开复用资源；没有另建 WebGL 上下文。

## 目标仍未完成的项目

1. 敌方机体依然使用 1.2 的较简化模型，其结构和材质还没有达到新主角的细化程度。
2. 主角近景材质与关卡的大面积材料仍存在风格落差，需要统一照明、尺度、细节密度和战斗视觉层次。
3. 急转、移动瞄准、斜向冲刺、各装备骨架缩放等组合动作还需针对性姿态/脚底检查，直线采样和通关不能代替这些检查。
4. 整体生产级观感没有被证明。当前工作完成的是机械身体与检视这一阶段，保留完整升级目标为 active。

下一阶段先改造敌方承力结构与机械动作，并验证复杂移动的身体姿态，再做整体画面审查。不要把本文件的通过项或离线包校验解释成全部目标完成。
