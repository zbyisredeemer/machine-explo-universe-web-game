## 检查结果

- `npm test`：4 项通过，覆盖推进顺序、解锁、装备购买与存档有效性。
- `npm run build`：生产构建成功。Three.js 使单个 JavaScript 包大于 Vite 的默认体积提示阈值；这是体积提醒，构建无错误。
- `node tests/playthrough.mjs`：四章真实键盘通关通过，浏览器运行时错误为空。
- `node tests/branches.mjs`：另一结局、四种模块、文明揭示和伙伴选择通过。使用来源于完整通关的有效存档作为分支检查起点，个别独立机制通过定位角色或注入伤害建立测试条件。
- `node tests/showcase.mjs`：四章最终文明场景均能渲染，运行时错误为空；已检查截图。
- `node tests/production.mjs`：生产入口、键盘移动、设置、紧凑窗口、刷新继续均通过；无外部资源请求；生产环境没有 QA 全局入口。
- Python 启动器编译检查通过，本地服务健康接口返回 `alien-body / 1.0.0`。

浏览器测试中修正过精确按钮选择器与动画帧等待逻辑，最终报告以 `playthrough.json`、`branches.json`、`showcase.json`、`production.json` 的通过结果为准。

## 规模与运行边界

交付为完整可玩的独立短篇，采用紧凑关卡和程序化低多边形美术。大型商业单机的内容体量、电影级素材、开放宇宙模拟、真人配音与实时生成式 AI 对话不属于当前实现。主要支持桌面键盘鼠标，需 WebGL 2。存档保存在当前浏览器和地址下，切换浏览器或清除站点数据不会自动迁移进度。
