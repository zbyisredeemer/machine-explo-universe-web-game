# 隐私与本地数据

游戏本身没有账号、广告、分析 SDK、cookie 跟踪、网络接口或遥测。程序化画面和合成音效均在浏览器中生成。使用离线发行包不需要联网。

浏览器 localStorage 保存：主存档 `alien-body.save.v1`、前一个有效检查点 `alien-body.save.backup.v1`、设置 `alien-body.settings.v1`。存档包含剧情进度、装备、游玩时长和游戏内统计，不要求姓名、邮箱等信息。数据保留到玩家清除站点数据；“新的旅程”替换主进度，旧检查点可能暂留于自动备份。彻底删除应清除该地址的站点数据。

浏览器/地址/端口之间不会自动同步。更换前请导出 JSON，导入时会预览并要求确认。导出文件留在玩家选择的本地位置；诊断导出也不会自动发送。

诊断仅包含游戏版本、运行模式、画质、窗口尺寸、WebGL 版本和存储是否成功，不包含存档正文、网址、浏览器标识、用户名或设备标识。

公开网站的托管服务可能产生服务器访问日志；这属于部署者的数据处理，需要部署者另行披露。项目文档不代表任何尚未配置的托管服务隐私政策。
