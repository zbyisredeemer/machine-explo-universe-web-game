# 操作与射击验证

日期：2026-10-05

## 本轮结果

移动基准速度从 9 提升至 10.8，再乘以底盘系数。方向归一化，精确积分速度响应，急转与刹停更快；碰撞移动采用最多 1/120 秒步长。冲刺速度 43、持续 0.19 秒、冷却 0.28 秒，冲刺中可转向；消耗 22 能源（逐星 14），恢复 24/秒，原有章节奖励继续生效。空中方向控制与地面一致，跳跃及冲刺加入 130 毫秒缓冲。切换模式、失焦、指针取消都会清理连射与缓冲。

鼠标屏幕位置决定瞄准射线；辅助只选择短边 6.5% 半径内的目标。K 使用原有方向辅助，L / 中键可锁定。屏幕射线确定意图后，从实际枪口查询最近命中，伤害和显示共用结果。开火前抬枪，枪管持续对齐；移动射击不降速。准星附近的小圆点是实际落点，遮挡时显示橙色状态。

脉冲枪与光束矛采用双层渐隐光束、独立枪口闪光、定向火花、冲击环与不同音色；命中音和标记只在实际命中时触发。共享固定几何，临时透明材质随效果销毁，效果队列设有上限。减少动态模式去掉外层光束、冲击环和准星扩张，低画质减少火花。

## 范围与限制

当前敌人采用球形命中体积，没有逐三角形、部位弱点或爆头判定。遮挡覆盖主要静态箱体建筑，未声称所有装饰、植被及活动门均参与弹道碰撞。键盘辅助仍比鼠标范围宽；鼠标自由准星与原来的右键拖动视角并存，没有强制鼠标锁定。

测试确认输入、命中和动作稳定性；“极度灵活”的主观手感仍需要玩家亲手体验后微调。本轮没有宣称在所有硬件上达到固定帧率。

回归过程中发现并修复：射线起点位于敌方命中球内部时，应按距离零计算首次接触，不能使用球的出口距离。已加入纯射线测试与真实键盘贴身开火回归。近战命中标记也会更新到本次命中位置，避免沿用上一发枪弹的坐标。
