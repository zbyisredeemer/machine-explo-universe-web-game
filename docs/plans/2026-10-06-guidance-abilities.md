# 任务提示与主动技能反馈

用户要求：继续优化操作、任务提示和主动技能释放特效。

选择：保留立即释放和已有战斗节奏，使用情境提示与可选 X 范围预览；不增加强制教学弹窗或把 F 改为蓄力释放。四种技能用不同的空间形状、持续时间与音色表达其作用。

实现结构：

- guidance.js：计算任务下一步、当前有效目标、互动按键与技能可释放状态。F 实际判定和技能面板读取同一状态。
- guidance-hud.js / guidance.css：任务行动提示、实时清理数量、左侧技能面板、技能释放结果与阻塞原因。战斗中心留给角色和瞄准。低高度窗口缩小辅助信息。
- ability-effects.js：独立管理主动技能临时对象、材质、计时与 X 预览。重力收束、共生上升、时差时钟与折跃两端各有独立形状；低画质减少粒子，减少动态时只保留简化形状，暂停冻结计时，场景切换释放材质。
- game.js：发送实际释放结果，统一读取释放条件，提供纯位置计算的折跃落点，保留原伤害、消耗、冷却与通路条件。

验证：状态单测、真实键鼠四种技能预览和释放、拒绝重复释放、能源不足、错模块/正确模块通路操作、任务战斗前后变化、暂停、资源回收和小窗口截图；回归上一轮战斗与四模块/结局分支，并构建离线版本。
