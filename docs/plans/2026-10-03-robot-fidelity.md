# 机器人可信度与交互升级

上一轮是实际进展：四章结构、差异攻击、扫描与支线已经写入可运行代码并经过通关。但当前人物仍呈现圆角积木与无落地约束的摆腿动画，不能以旧测试通过认定本轮目标完成。

## 目标与证据

1. 工业探索机器人：明确的承力骨架、独立护板、旋转执行器、伸缩连杆、线束、手指与传感器。材质区分喷涂合金、裸露金属、橡胶和光学玻璃。以近距离转台实机图核验结构连接、比例与材质。
2. 可信运动：髋膝踝双段逆运动学，支撑脚接地，摆动脚抬起，速度变化控制步频，急停和转身重心响应。录制真实键盘运动序列，同时采样脚底高度和支撑脚滑移。
3. 身体反馈：瞄准与工具出口对齐，后坐力、落地缓冲、受击姿态，头部注视目标和附近交谈对象；脚步与执行器声音对应动作。
4. 近距离身体检视：玩家能看到新结构，并可转动、缩放、展示动作和查看部件。操作与退出不污染游戏状态。
5. 保留完整四章流程、旧档、低配置与离线运行。性能、异常恢复和可访问交互需要新证据。

工业探索型优先。仿人型需要更复杂面部与全身动画，重型机甲会偏离轻巧探索的原有玩法。当前先完成共用运动与材料系统，用户风格反馈可继续融入。

## 完成审查

不能仅凭构建、数值测试或素材数量认定生产级观感。需核验近景、运动录制、战斗中的瞄准/脚步，以及交互可达性；保留未证明项目，目标保持 active 直到充分完成。
