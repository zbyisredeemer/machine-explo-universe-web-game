# 1.1 交互与效果升级

目标：将已有四章完整游戏升级为可稳定交付的精修版本，保留旧存档与原有完整流程。

1. 操控：平滑启停与转身、锁定目标、输入缓冲、冲刺拖尾、命中停顿、近战弧光、完美闪避反馈。
2. 画面：可降级 HDR 辉光、星球程序纹理与大气、环境粒子、圆角机体、甲板细节、能力视觉语言和镜头动态。
3. 界面：冷却进度、目标锁定标记、浮动伤害、任务阶段进度、近距离交互反馈、键盘焦点、菜单返回行为与可选减少动态效果。
4. 可靠性：存档校验与自动备份、导入导出、存储拒绝时仍可游玩、失焦输入复位、图形上下文恢复、特效和渲染资源上限。
5. 验证：单元测试覆盖坏档和输入/瞄准边界；真实键盘四章回归；新交互与图形异常分支；生产构建、可视截图、短时性能及资源稳定性检查。

生产交付标准：全部章节和结局仍可完成；旧存档可继续；新增效果有低配置和减少动态效果选项；无已知阻断性错误；测试与构建通过；源码、说明、本地启动器和离线包一致。
