# 操作与射击手感

用户要求：继续优化操作、射击特效、瞄准，走位需要极度灵活。

本轮选择快节奏动作方向：提高响应、允许冲刺转向、完整空中控制；保留原有键位、四章任务与存档。不采用会强制鼠标锁定的新控制模式，也不加入与走位目标相冲突的射击减速或随机散布。

实现：

1. 按指数响应精确积分速度，碰撞移动以最多 1/120 秒细分。方向归一化，避免斜向更快。冲刺 0.19 秒、冷却 0.28 秒、消耗 22（逐星 14），能源每秒恢复 24。跳跃和冲刺各有 130 毫秒输入缓冲。
2. 鼠标使用屏幕射线，键盘保留方向辅助选敌；鼠标辅助半径为短边 6.5%。枪口独立查询最近命中点，静态主要建筑参与遮挡。敌人使用球形命中体积。视野预览和实际射击共用查询。
3. 瞄准时朝向目标，移动方向独立；开火前抬枪并对齐，枪管姿态持续追踪。镜头加快跟随，伤害顿帧不阻塞玩家输入。
4. 添加双层渐隐弹道、枪口闪光、命中点火花及冲击环、两种音色与命中提示音。GPU 临时材质随效果释放，保留数量限制。低画质和减少动态选项限制装饰。
5. HUD 每帧更新准星与实际落点，显示遮挡、目标及冲刺恢复状态；模式切换、失焦及指针取消时清理输入。

验证：单元测试覆盖帧率差异、反向刹停、射程、遮挡和最近命中；浏览器验证真实鼠标/键盘、手动瞄准、锁定横移、冲刺转向、空中转向、缓冲与暂停恢复；回归三种底盘动作和章节流程。
