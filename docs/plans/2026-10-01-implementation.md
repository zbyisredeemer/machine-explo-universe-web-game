# 异星之躯 Implementation Plan

**Goal:** 完成可本地运行的 3D 单机动作冒险，包含四章、机器人改造、伙伴生活、存档与结局。

**Architecture:** Three.js 负责三维场景和角色，DOM 负责中文界面。纯函数管理章节状态和存档校验，游戏循环管理输入、物理、敌人和互动，数据驱动不同章节的叙事与外观。

**Tech Stack:** JavaScript ES modules、Three.js、Vite、Node test runner、Playwright。

## 实施步骤

1. `src/data.js`、`src/state.js`：章节、装备、事件、存档；`tests/state.test.js` 验证解锁顺序、升级限制、坏档恢复与结局。
2. `src/world.js`：程序化机器人、四类文明环境、飞船据点、敌人、特效、场景资源回收。
3. `src/game.js`：第三人称移动、冲刺、跳跃、近战、射击、敌人预警、重力牵引、生态恢复、时间减速和空间折跃。
4. `src/ui.js`、`src/style.css`：主菜单、战斗 HUD、对话、日志、星图、改造、暂停、设置、失败重试和结局。
5. `src/main.js`：连接各模块、初始化错误处理；补全飞船生活、重访和自动存档。
6. `tests/playthrough.mjs`：浏览器验证实际输入与截图，再逐章验证互动、敌人、技能、Boss、结局和读档。测试辅助入口仅在开发且显式开启测试参数时存在。
7. `README.md`、启动脚本与生产构建：提供清楚的启动、操作和本地存档说明。执行 `npm test`、`npm run build`、`npm run test:e2e`，对渲染画面进行人工检查。

## 完成检查

- 所有四章有入口、任务、模块、独立环境、战斗、发现及返回飞船路径。
- 移动、空中冲刺、近战、射击、部件破坏、能力与敌人伤害实际运行。
- 伙伴响应真实事件，装备改变数值与外观；重访保留关键状态并提供感知解锁内容。
- 可暂停、调整音量与画面、死亡重试、刷新继续；存在可到达的结局并能继续探索。
- 无必要外部素材或在线 API 依赖；安装后可断网运行本地构建。

用户已明确要求直接制作，因此在当前会话顺序实现，不再进行执行方式确认。
