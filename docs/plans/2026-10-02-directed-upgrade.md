# 1.2：从功能完整转向有辨识度的游玩体验

用户反馈 1.1 仍然差点意思。不能继续把构建通过和特效数量作为成品质量的替代证据。

## 本轮实际改造

1. 重做四章空间美术，去掉贯穿四章的重复斜柱和平板走廊。巨舰采用工业舱段与反应堆；花园采用有机温室与树根结构；慢速之海采用悬浮拱廊和钟摆城市；最终星域采用悬空神殿与星图网络。
2. 重做角色与敌人模型：分节关节、头盔面罩、机械背包、可见武器、机械足和差异化守卫轮廓。动作区分奔跑、空中、射击和近战。
3. 引入各章独有的战场危险与守卫招式、明确预警与反击窗口；新增可持久保存的支线互动，给予探索实际后果。
4. 加入真实场景的开场镜头、可跳过的区域/守卫演出、扫描环境的能力和随任务变化的场景反馈。
5. 调整灯光、环境反射、气氛与 HUD，在实机截图和实际输入中验证明显提升；保留旧存档、四章、结局和低配置选项。

## 验证门槛

- 每章从场景轮廓、战斗变化和互动内容都能辨别。
- 对比旧版截图，角色与环境明显更完整，关键交互仍清楚可读。
- 实际击败不同守卫、处理新危险、完成新支线与旧主线；验证旧档迁移与重访后果。
- 构建、回归、生产入口、性能与资源检查通过。保留真实限制，不能把短期测试说成全平台认证。
