# 支持范围与质量门槛

本版本定位为可自托管、可离线分发的独立短篇发布候选。商业发行是产品与平台验收过程，不以一次自动化通过替代。

## 发布门槛

`npm run verify` 必须完成：ESLint、格式检查、规则/存储单测、启动器与打包拒绝过期证据的测试、npm 官方审计、生产构建、JS gzip 总计不超过 350,000 字节，以及 15 组 Chromium 回归。覆盖操作训练、补给探索与独立声音设置、四章通关、两个结局、伙伴、装备、保存刷新、技能、视觉主题、输入清理、GPU 资源边界、导入导出、图形设备恢复和生产无 QA 入口。

验证结果绑定源文件、构建产物和各组报告的 SHA-256。任何受检代码、构建或报告变化必须重新验证，不能通过修改时间戳获得发行包。证据用于可追溯性，不是数字签名或第三方认证。

## 当前支持边界

- 主要目标：桌面键盘鼠标、支持 WebGL 2 的 Chromium 浏览器，建议窗口至少 960×640。
- Node 只用于开发；离线启动器需要 Python 3.10+。Windows/Linux 启动器已提供，实际平台结果以验证报告为准。
- 手机触控、手柄、屏幕阅读器完整游戏流程、多人、云存档、账号和支付尚不支持。
- 低画质、减少动态效果、音量与故事难度可选；菜单支持键盘焦点。不能宣称符合完整无障碍标准。
- 自动化帧耗时只代表当次机器/浏览器，不构成最低显卡规格或所有硬件帧率保证。

## 收费上架前的人工验收

在实际销售的 Windows/macOS/Linux 与显卡组合上通关、测试离线/升级/存档迁移；执行至少 60 分钟持续游玩；让未参与开发的玩家验证引导、手感和内容时长；确认商品页准确披露短篇规模、系统要求与存档方式；完成所选商店要求的评级、权利声明和发行人资料。不要宣称已取得尚未取得的商店认证。

本仓库可准备代码、构建和技术证据；发行人、商店账户及未提供的测试硬件需要项目负责人补充。
